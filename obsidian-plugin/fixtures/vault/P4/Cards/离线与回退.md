# 离线与回退：阅读不依赖检索模型

离线有两种不同场景。已有 Markdown 卡片和内链可在阅读器里直接打开，不需要检索模型；要做语义检索，则应预先安装依赖与经过校验的本地嵌入模型。准备完成后，模型计算在本机进行，Obsidian 本身也不必同时运行。首次安装依赖或获取模型所需的联网，不应被混称为查询时上传资料。

缺少模型时，关键词检索仍可能可用，但它不能冒充完成了向量或混合查询。调用方需要明确允许回退，并核对返回的实际模式；没有可用索引时，应先准备索引或明确说明无法检索。可回到[组件边界](入口.md)理解阅读和检索的区别；缓存、卡片和路径如何保留，再看[数据保护](数据保护.md)。
