# 接页 Carddesk 0.3.4：本地测试版

包含渐进阅读插件、可单独安装的本地检索工具、原创示例库。插件不接 AI，不需要模型或 CLI 才能阅读。检索使用 QMD 2.9.0、本地嵌入模型；拆卡和关联判断由用户授权的本地 Agent 完成。

这版完成本地安装与流程验收；进一步混合优化、独立来源/第二评审、千卡/万卡性能按用户决定暂缓。只验证当前 macOS 环境，不表示已通过跨平台或插件市场审核。

## 插件安装

解压 carddesk-plugin-0.3.4.zip，将其中 carddesk 文件夹放到目标库的 `.obsidian/plugins/`。重启 Obsidian，在第三方插件中启用“接页 Carddesk”。仅在你信任插件来源的库启用。

升级时先备份 `.obsidian/plugins/carddesk/`，只替换 main.js、manifest.json、styles.css；保留 data.json。不要将另一个库的 data.json 覆盖过来。普通 Markdown 卡和导出的 Agent 说明都在 Vault 里，升级不应覆盖它们。

## 示例库

解压 carddesk-example-vault-0.3.4.zip，在 Obsidian 选择“打开已有文件夹作为库”。插件已放在 .obsidian/plugins/carddesk，但没有预先启用；启用后打开 P0/A，运行“以接页渐进阅读当前笔记”。点击 B/C，再各自点 D，试收起、返回上层和循环返回。

P2/入口用于共享分支与路径保存；Carddesk/packages/p3-example.json 用“检查 Agent 卡片包”命令检查。示例为原创测试讲义；不含用户 AIPM PDF、个人阅读状态、模型、node_modules 或密钥。

## 检索工具安装

解压 carddesk-tools-0.3.4.zip，在解压目录执行（需 Node 22+、npm、Python 3、curl）：

```sh
CARDDESK_NODE=/usr/local/bin/node sh release/setup-search.sh
sh reuse-eval/aipm/download-model.sh
```

Node 路径按本机调整。setup-search 仅按锁文件安装本工具私有依赖，首次依赖和模型准备需要联网。模型下载约 639 MB，经大小/GGUF/SHA-256 校验；已有缓存只校验。已有代理可仅为下载命令设置 CARDDESK_MODEL_PROXY。离线部署可事先准备依赖，并复制已校验模型到工具 `.reuse-eval/cache/qmd/models/`；不必复制旧索引。

也可在 init 指定现有模型 `--model /absolute/model.gguf --model-sha256 <对应SHA256>`，避免重复存一份模型。测试使用的官方 Qwen3-Embedding-0.6B-Q8_0 文件 SHA-256：06507c7b42688469c4e7298b0a1e16deff06caf291cf0a5b278c308249c3e439。

初始化时将 Vault 路径替换成真实绝对路径，索引状态放到 Vault 外。已有配置不会被 init 覆盖：

```sh
/usr/local/bin/node search/cli.mjs init --vault '/absolute/示例库' --cards Cards/P3 --state '/absolute/carddesk-search-state'
/usr/local/bin/node search/cli.mjs refresh --state '/absolute/carddesk-search-state'
/usr/local/bin/node search/cli.mjs search --state '/absolute/carddesk-search-state' --mode hybrid --question '怎样保留证据并判断两张卡是否有关？' --keywords '来源 关联' --limit 5
/usr/local/bin/node search/cli.mjs get --state '/absolute/carddesk-search-state' --path 'Cards/P3/来源.md'
```

依赖与模型准备完后可离线运行；Obsidian 不必启动。卡片增删改名后先 refresh。模型缺失时阅读插件不受影响；可用 `refresh --keyword-only` 准备关键词，或在获准时显式加 `--allow-keyword-fallback`，核对 actualMode/fallbackReason，不能冒充混合成功。

普通关键词用空格分隔，最多 8 个；引号、排除词保留 QMD 语法。宽召回可能返回不能回答的问题，必须 get 全文核对，不根据分数直接加链接。当前范围只限制配置目录，不是按用户身份的文档授权系统。

## 从 Agent 到阅读

在插件导出三份 Agent 说明，向本地 Codex/Claude Code 指定项目/工具绝对路径、Vault 和授权范围。让 Agent 保留 raw、拆卡、检索旧卡、读取全文、输出关联建议和包清单；Agent 需有用户单独授予的文件权限。插件不运行 Agent，不自动批准关联。

审阅建议后才修改授权卡片；更新索引；在插件校验包并打开入口。展开几层/多分支后运行“保存当前阅读路径”，命名。退出整个 Obsidian 再启动，通过“打开已保存的阅读路径”恢复。

## 回退与卸载

先退出 Obsidian。回退插件只恢复备份的三个程序文件，保留当前 data.json；跨数据格式版本前另行备份状态，不能猜测兼容性。卸载可在第三方插件里关闭/移除接页，或将其插件目录移到备份位置；卡片和原文仍是普通文件，命名路径保存在 data.json，先备份。

检索索引是派生数据。损坏时先停止所有检索，备份状态目录，保留 config.json，将 index.sqlite 及其 -wal/-shm 和 snapshot.json、embedding-model.json 移到隔离备份后 refresh 重建。不要在有操作运行时搬动数据库。原文/卡片不能当作索引一起删除。

卸载检索只需移走工具目录及明确属于此工具的状态目录；若模型由多个工具共用，不要删除共用模型。setup 不注册后台服务、不改系统代理或全局 npm 配置。

SHA256SUMS.json 记录包和内容校验；P4 验收及待办见随包文档。初始发布后发现的新问题应追加到项目测试与优化决策日志。
