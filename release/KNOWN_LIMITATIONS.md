# 接页 Carddesk 0.3.4：已知限制

本版本作为 GitHub 预发布测试版提供。

- **平台范围**：实际验证环境为 macOS、Obsidian 1.9.14；插件声明最低 Obsidian 1.8.7。Windows、Linux、移动端和更多窗口尺寸组合尚未验证。尚未上架 Obsidian 社区插件市场，需要手动安装。
- **AI 分工**：插件不连接生成 API，不运行 Codex/Claude Code，也不自动拆书、判断关联或批准加链。本地 Agent 需要用户单独授予目录访问权限；PDF 提取/OCR 在插件之外完成。
- **检索依赖**：插件阅读不依赖检索工具或模型；关键词/向量工具需要 Node 22+ 及 QMD 2.9.0。向量/混合还需要预先准备约 639 MB 的本地嵌入模型，发布包不含权重。首次依赖安装与模型获取需要联网，准备完成后可离线查询。
- **检索质量**：宽召回可能返回主题相近但不能回答的卡片，混合也可能遗漏次要解释，不保证全面优于关键词。分数不是事实或关联证明，必须读取全文并核对来源；没有依据应拒绝回答或加链。
- **访问控制**：允许/排除目录是当前工具的范围约束，不代替操作系统权限或按用户身份的文档授权系统；没有通用的时间、版本、权限元数据过滤服务。
- **更新与并发**：没有后台监听或常驻服务。文件增删改名、范围或模型变化后需要显式 refresh；陈旧索引会拒绝查询。命令互斥，不支持同时运行多个写索引操作。
- **规模与泛化**：进一步混合检索优化、独立来源与第二评审、千卡/万卡性能测试尚未完成；不承诺大库延迟、内存或跨领域质量。不能把现有小规模流程验证当作完整产品有效性证明。
- **阅读与状态**：阅读树限制为 100 节点，卡片检索上限为每文件 1 MiB。不提供内置聊天、自动关联执行、跨设备索引同步或旧数据库全量迁移。升级前应备份库及插件 data.json；程序文件、阅读状态、卡片与派生索引应分别保留和恢复。

公开附件仅包含程序、通用说明、锁文件和原创示例，不含用户书籍/PDF、私人笔记、个人阅读状态、材料评测题集、验收报告、决策日志、密钥、依赖缓存或模型权重。
